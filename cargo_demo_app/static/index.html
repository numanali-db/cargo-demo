An end-to-end Databricks Data Intelligence Platform demo. The agent dynamically prices inbound forwarder RFQs using a real ML yield model, capacity analysis, competitive intelligence, and IATA / carrier-specific handling rules. Every component is a discoverable workspace asset.

Agent invocation flow

  1. App receives POST /api/rfq/{id}/analyze
  2. App invokes cargo-yield-agent serving endpoint with the RFQ payload
  3. Agent runs 5 steps (each as an MLflow trace span):
    • capacity_check — SQL warehouse → silver/bronze
    • yield_calc — calls cargo-yield-model + historical fallback
    • competitive_check — SQL warehouse → gold
    • rules_retrieval — Vector Search
    • quote_drafting — Claude Sonnet 4.6
  4. Agent returns structured trace; App renders it in the cockpit
  5. Every invocation logs a trace to MLflow — queryable for audit, eval, debugging

Data scale

  • 123,011 synthetic AWBs across 12 months
  • 7,015 flights, 17 active lanes
  • 15 forwarders across 4 tiers (Platinum / Gold / Silver / Bronze)
  • 12 commodity codes including PHC, PER, AVI, VAL, DGR
  • ~£272M synthetic cargo revenue (calibrated to VAA FY24 £236M)
  • 15 knowledge base documents indexed in Vector Search
  • 714 competitor rate observations across 7 carriers
